# dsa-practice

Personal practice repo for Data Structures & Algorithms problems, organized by topic.

## Structure

```
Programs/
├── Arrays/
├── LinkedList/
├── Stacks/
├── Queues/
├── Trees/
├── Graphs/
├── HashMaps/
├── Sorting/
├── Searching/
└── DP/
```

Each topic folder contains:
- `README.md` — a problem tracker table (add rows as you solve problems)
- A `*Starter.java` file — replace/extend with your actual solutions

## Language

Java (adjust as needed per problem).
